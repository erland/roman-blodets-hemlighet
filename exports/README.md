# Exporter

Denna katalog innehåller metadata om genererade exporter, till exempel EPUB eller PDF.

Exporter är inte romanens kanoniska källtext. De kan återskapas från `kapitel/kapitel-XX.md`.

När användaren begär EPUB eller PDF ska export skapas som separat nedladdningsfil.

## Omslagsbild

Aktiv omslagsbild finns i projektzipen som `omslag/blodets_hemlighet_den_forsta_gnistan.png` och kan användas vid EPUB/PDF-export.
